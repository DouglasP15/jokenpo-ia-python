🐻🐍🦅 Jokenpô Animal

Um jogo de Pedra, Papel e Tesoura para dois jogadores, com tema animal e interface minimalista. Desenvolvido a partir de um script Python (Google Colab) e convertido em uma página web interativa, pronta para publicar no GitHub Pages.

Sobre o projeto

Este projeto nasceu de um notebook Python criado no Google Colab com a lógica clássica de Jokenpô para dois jogadores. A ideia foi transformar esse script em uma experiência visual moderna, temática e fácil de compartilhar — sem dependências externas, sem frameworks, sem servidor.

Cada jogada ganhou um representante animal:

Jogada	Animal	Regra
🗿 Pedra	🐻 Urso	Amassa a Águia
📄 Papel	🐍 Cobra	Envolve o Urso
✂️ Tesoura	🦅 Águia	Corta a Cobra
Funcionalidades
Coleta os nomes dos dois jogadores antes de iniciar
Turnos separados — jogador 2 não vê a escolha do jogador 1
Placar acumulado ao longo das rodadas
Tela de resultado com descrição do duelo
Tela de regras acessível a qualquer momento
Totalmente responsivo para mobile e desktop
